# ADR 0013: English as the project language

- Status: accepted
- Date: 2026-09

## Context

The original proposal is written in Spanish, but code, tools, libraries, and the future public repository favor English. Mixed-language identifiers, commits, and comments add noise.

## Decision

Use English everywhere: code, identifiers, tests, documentation, UI, and commits. No comments in code. No emojis. Conventional Commits in English with scope.

## Consequences

- Consistent identifiers and searchable history.
- The original proposal artifacts in `docs/proposal/` remain in Spanish as historical sources.
- No code comments means names and structure must carry the intent; this raises the bar for naming.
