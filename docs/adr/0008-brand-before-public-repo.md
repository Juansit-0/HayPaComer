# ADR 0008: Branding before the final name and public repository

- Status: accepted
- Date: 2026-09

## Context

"HayPaComer" is a working name. The repository, packages, and documentation should carry the final name once, not be renamed twice with public history noise.

## Decision

Run the branding phase first. The public GitHub repository is created at brand close with the final name; if the name changes, folder, modules, packages, and repository are renamed together.

## Consequences

- No public repository exists until branding closes.
- One coordinated rename instead of scattered renames.
- Local work is versioned in git the whole time.
